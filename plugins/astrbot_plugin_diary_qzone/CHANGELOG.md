# Changelog

## 1.2.0

- 新增：`owner_ids` —— 只有名单里的 QQ 说「晚安」才写日记并发空间。
  留空时回退到 AstrBot 的 `admins_id`；填 `*` 回到旧行为。
  这样小号对外后，别的好友说晚安不会占掉今天唯一的名额、也不会把日记发到你空间
- 修复：`/日记状态` 在「晚安触发：开」时 `owners` 未定义，会抛 `NameError`
- 优化：`persona_id` 可显式指定，不再依赖「当前默认人格」（人分了主号/对外两套时必需）

## 1.1.0

- 新增：`activity_feed_enable` 与 `{activity}` 占位符，可读取 `astrbot_plugin_observe_life` 的今日摘要，
  让日记带上当天活动的底色（未安装该插件时自动跳过）
- 新增：发布失败时把正文存进 `pending.json`，开机后自动补发，超过 36 小时丢弃
- 新增：`/日记状态` 中显示待补发状态与当前生效人格
- 优化：晚安触发改为后台任务，不阻塞她的正常回复
- 优化：日记清洗更严格，去掉代码块、标题、日期行与「日记：」前缀
- 优化：触发词按长度倒序匹配，避免「睡了」抢先命中「我睡了」
- 修复：定时兜底与手动写入并发时可能重复发布
- 调整：`notify_umo` 默认值改为空（不同步到聊天，只发空间）

## 1.0.0

- 首次发布：晚安触发写日记 → 发布到 QQ 空间
- 支持 Cron 定时兜底（默认关闭）、随机浮动、可见范围控制
- 命令：`/写日记`、`/日记预览`、`/日记状态`
